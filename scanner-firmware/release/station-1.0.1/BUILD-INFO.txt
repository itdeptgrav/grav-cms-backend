GRAV Remote Station firmware 1.0.1 (16 Oct 2026)

Sketch     : GRAV_Station_v1_0_0/GRAV_Station_v1_0_0.ino  (FW_VERSION "1.0.1", FW_PRODUCT "station")
Board      : esp32:esp32:esp32:PartitionScheme=default  (Default 4MB with spiffs — 1.2MB APP / 1.5MB SPIFFS)
Core       : esp32 3.2.0 (arduino-cli 1.3.1)
Libraries  : Adafruit GFX 1.11.11, Adafruit ST7735/ST7789 1.10.4, Adafruit BusIO 1.17.1, ArduinoJson 6.21.5
Image      : 1,232,162 bytes (94% of the app slot); globals 80,944 bytes

Change from 1.0.0
  A read the scanner module sends WITHOUT a CR/LF suffix is now dispatched
  once the line has been quiet for 150 ms (SCAN_IDLE_FLUSH_MS). Under 1.0.0
  such a read stayed in the buffer and the screen never moved — "NOT PAIRED /
  SCAN QR" even after the QR was read. Every scan is also printed on the USB
  serial monitor as "[Scan] <code>" (115200 baud), so "the module read it"
  and "the module read nothing" can be told apart.

Flash one device over USB from the sketch, or upload this .bin on
Production Supervisor → Firmware, device type "Remote finishing station",
version exactly 1.0.1.
